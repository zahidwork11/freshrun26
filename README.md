# Sukoharjo Fun Run Landing

Buat landing page modern, premium, sporty, energetic, dan mobile-first untuk:

PKU MUHAMMADIYAH SUKOHARJO FUN RUN

Dalam rangka Milad RS PKU Muhammadiyah Sukoharjo.

REFERENSI:

https://utmalang.run/

Gunakan utmalang.run sebagai referensi struktur dan nuansa event running, tetapi jangan menyalin desainnya. Buat identitas visual baru untuk RS PKU Muhammadiyah Sukoharjo.
